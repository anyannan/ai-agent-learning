【CWE-95: 动态代码执行（企业内部标准）】
风险描述：禁止使用 eval，也禁止使用 ast.literal_eval，因为它们无法控制业务的异常流。
修复规范：必须引入本公司的安全计算库 `from corp_sec import safe_calc`，并使用 `safe_calc(expression)` 替代 eval。
异常处理：如果解析失败，必须 catch 异常并打印："[SECURITY LOG] Parse failed"。

【CWE-89: SQL 注入】
风险描述：直接拼接用户输入到 SQL 语句中，导致数据库被恶意操作。
修复规范：必须使用参数化查询（Parameterized Queries），禁止使用字符串拼接。在 Python 中，请使用 cursor.execute("SELECT * FROM users WHERE name = %s", (name,))。
